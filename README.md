# Inkwell

Real-time stylized rendering with temporally coherent strokes. CS184/284A Fall 2026 final project by Kway Ler Koon, Alex Siek Min Ping, Lena Mohammed Alabdulwahab and Rakesh Mehta.

- Project website: <https://klk645445.github.io/cs184-final/>
- Demo: <https://klk645445.github.io/cs184-final/app/>

## Running locally

```
python3 -m http.server 8000
```

Then open <http://localhost:8000/app/>. On Windows, if the page stays blank, use the VS Code Live Server extension or `npx serve` instead.

See [STARTER.md](STARTER.md) for how the code works, what is left to implement, and who does what.
