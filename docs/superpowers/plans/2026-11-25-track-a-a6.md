## Contract

For each pixel where `warped.valid` is true, classify current and warped masks
with strict `>0.5`. Count union pixels and pixels belonging to exactly one mask.
Return changed/union, or NaN for an empty eligible union. Ignore the unwarped
previous mask; keep the existing three-argument interface used by Harness.js.
Do not mutate inputs. No new tunables or shared pipeline/UI changes.

A5 excludes background and uses a heuristic depth gate. Consequently this metric
does not assess rejected/disoccluded pixels or exterior hull-only background strokes.
An empty union is missing evidence, not perfect stability. A6 measures flicker;
it does not add temporal stabilization or implement teammate C4 coherence.
